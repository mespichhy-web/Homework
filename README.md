# HTML Document Structure Homework

A responsive HTML/CSS recreation of the supplied document-structure reference.

## Files
- `index.html` — semantic HTML layout
- `style.css` — colors, spacing, borders, and responsive layout

## Run in VS Code
1. Extract this project folder.
2. Open VS Code.
3. Select **File → Open Folder** and choose `document-structure-homework`.
4. Open `index.html`.
5. Right-click the editor and choose **Open with Live Server** (if the Live Server extension is installed), or open `index.html` in your browser.

## Upload to GitHub
Create an empty repository on GitHub, then open the VS Code terminal in this folder and run:

```bash
git init
git add .
git commit -m "Create responsive HTML document structure"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

Replace the remote URL with your own GitHub repository URL. If Git asks you to sign in, complete the GitHub authentication prompt.
